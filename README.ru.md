# Перенос контента pf2e на Foundry v13

Свежие книги Pathfinder 2e на Foundry v13, без перехода на v14.

Разработчики pf2e заморозили ветку v13 на релизе 7.12.2 и ушли на v14. Всё вышедшее после, включая Impossible Magic, Hell's Destiny, Bastion of Blasphemies, Lost Omens High Seas, Secrets of the Unlit Star, Troubles in Grayce и NPC Core, доступно только на v14.

Здесь оно переносится на v13.

## Установка

Вставьте адрес манифеста в окно установки системы в Foundry.

```
https://github.com/def-gu/pf2e-v13-backport/releases/latest/download/system.json
```

Идентификатор системы остаётся `pf2e`, поэтому существующие миры продолжают работать и ничего менять в них не нужно.

В пакете весь контент 8.4.0, это 29544 документа в 97 компендиумах, поверх кодовой базы 7.12.2.

## Сборка своими руками

Отредактируйте пути в `config.sh` и запустите стадии.

```bash
./run.sh fetch
./run.sh scope
./run.sh merge
./run.sh compile
./run.sh verify
sudo ./run.sh deploy
```

`scope` показывает, что изменится, до того как что-то меняется. `verify` проверяет собранное перед записью.

Нужны Foundry v13 с системой pf2e 7.12.2, Node и Python 3 на той же машине, возможность остановить сервер на время записи паков. Целевая платформа это Linux с systemd. На macOS стадию `deploy` придётся править, на Windows шелл-скриптам нужен WSL.

## Резервные копии

`deploy` копирует текущие паки, языковые файлы и манифест в `BACKUP_ROOT` до того, как что-либо записать, и печатает команду отката по завершении. Откат представляет собой копирование каталога.

Убедитесь, что умеете разворачивать эту копию, до запуска `deploy` на мире, который вам дорог.

## Перевод

Словари Babele привязаны к английскому названию документа, поэтому перевод, собранный под 8.x, работает на 7.12.2.

Берите ветку, собранную под ту же версию контента. Для 8.4.0 это `master` в [gnuraco/pf2r](https://gitlab.com/gnuraco/pf2r), покрытие около 90 процентов. Там же лежат переводы 83 модулей.

```bash
./scripts/sync-translation.sh
```

Скрипт опрашивает репозиторий ценой в 59 байт, подтягивает в поверхностный клон только изменившееся, делает копию установленных словарей и подменяет их. Пригоден для cron. После обновления перезагрузите мир, чтобы Babele подхватил изменения.

## Модули, собранные под v14

Большинство работает на v13 после правки объявлений. Проверьте модуль до того, как его трогать.

```bash
node scripts/check-module.mjs <каталог-модуля>
```

Проверка читает манифест, сверяет каждое обращение к API ядра с установленной сборкой Foundry и показывает, какой версией ядра помечены документы в компендиумах модуля. По итогу она говорит, достаточно ли портирования или нужны ещё правки кода.

```bash
node scripts/port-module.mjs <каталог-модуля>
```

Портирование переписывает `compatibility` в манифесте и `_stats.coreVersion` в компендиумах. Foundry отказывается принимать документы, помеченные версией ядра выше собственной, и это самая частая причина, по которой модуль под v14 выглядит сломанным.

## Обновление

Это снимок. После каждого релиза pf2e стадии запускаются заново, предварительно меняется `PF2E_TAG`.

`scope` сообщает, сколько документов заблокировано из-за отсутствующих rule elements. Пока там ноль, подход работает.
